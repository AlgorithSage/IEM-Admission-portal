## Defects found by the edge-case suite and fixed
| # | Severity | Defect | Fix |
|---|---|---|---|
| 1 | High | Registration only checked that fields were present: any email/password/phone accepted via the API | Server validates name, email, password (6-32), mobile; mirrors client BVA rules |
| 2 | High | Login passed request values straight to a MongoDB query (object payloads such as `{"$ne": ""}`) | Login/registration accept strings only |
| 3 | Medium | Empty files and non-documents renamed to `.pdf` were accepted | File signature (magic bytes) checked for PDF/PNG/JPEG; empty files refused |
| 4 | Medium | A file of exactly 5 MB passed the client check but failed on the server | Server limit aligned: exactly 5 MB accepted, 5 MB + 1 byte refused |
| 5 | Low | JWT verification did not pin the algorithm | `HS256` only |
| 6 | Low | Decision card: projected button rendered in one branch only | Single projection via template outlet |

## Edge cases covered (summary)
- Registration and login boundaries; duplicate email (case-insensitive); role mismatch.
- Tokens: missing, garbage, expired, wrong secret, `alg: none`, edited payload.
- Uploads: 0 bytes, exactly 5 MB, 5 MB + 1, disguised executable, wrong type, no file.
- Form: age 16/35 limits, percentages at min/max/decimals, exam ranks and marks at both bounds
  (including negative marks), application-number formats, duplicate/unknown/not-accepted exams,
  name/phone/PIN/address rules, streams, declaration.
- Submission: XSS in name, same file for two documents, oversized body, double-click submit.
- Payment: order without application, other user's order, tampered/missing signature,
  three simultaneous verifications (one ID, one payment).
- Access control: cross-applicant slip/document access, applicant on admin routes, malformed IDs,
  path traversal, injection-like filters.
- Decision rules: every illegal transition from Submitted, remarks required, approve with pending
  documents, Rejected is final, no replacement or reapplication after rejection, rejection email.

## Not covered (known gaps)
- Vercel Blob upload path is only exercised on Vercel (tests use the local driver).
- Real SMTP delivery (tests use the mock transport unless `E2E_USE_SMTP=1`).
